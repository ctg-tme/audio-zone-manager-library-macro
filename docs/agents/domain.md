# Domain documentation layout

This is a single-context repository.

- Read [`CONTEXT.md`](../../CONTEXT.md) before exploring or changing domain behavior.
- If present, read applicable ADRs under [`docs/adr/`](../adr/). ADRs record hard-to-reverse decisions; `CONTEXT.md` remains a glossary and must not become an implementation spec.
- There is no `CONTEXT-MAP.md`; do not look for per-package contexts unless the repository structure changes.
- Use the canonical terms from `CONTEXT.md` in issue titles, plans, tests, and documentation. If code and glossary disagree, call out the discrepancy before changing either.
